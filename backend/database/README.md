# إعداد قاعدة البيانات

ملف `schema.sql` ينشئ قاعدة بيانات فارغة باسم `zad` والجداول الستة التي يستخدمها
المشروع: `users` و`restaurants` و`products` و`orders` و`order_items`
و`restaurant_requests`. يحتوي الملف على بنية الجداول والفهارس والعلاقات فقط؛
ولا يحتوي حسابات أو طلبات أو بيانات شخصية من قاعدة التطوير.

## المتطلبات

- MySQL 8 أو MariaDB 10.11 أو إصدار متوافق.
- صلاحية إنشاء قاعدة بيانات للمستخدم الذي يستورد المخطط.
- PHP مع امتداد PDO MySQL للـ API.

## إنشاء قاعدة جديدة

من جذر المشروع، استورد المخطط باستخدام:

```sh
mysql -u root -p < backend/database/schema.sql
```

أدخل كلمة مرور مستخدم MySQL عند الطلب. ينشئ الملف قاعدة `zad` تلقائياً.
إذا أردت اسماً آخر، غيّر اسم قاعدة البيانات في سطرَي `CREATE DATABASE` و`USE`
في `schema.sql`، ثم استخدم الاسم نفسه في `backend/.env`.

لإنشاء مستخدم تطبيق محدود بدلاً من تشغيل التطبيق بحساب `root`، نفّذ في MySQL
مع استبدال القيم بكلمات مرور محلية قوية:

```sql
CREATE USER 'zad_user'@'localhost' IDENTIFIED BY 'replace-with-a-strong-password';
GRANT SELECT, INSERT, UPDATE, DELETE ON zad.* TO 'zad_user'@'localhost';
```

## إعداد التطبيق

انسخ نموذج الإعدادات ثم عدّل القيم على جهازك:

```sh
cp backend/.env.example backend/.env
```

ضع بيانات الاتصال الصحيحة في `backend/.env`. أنشئ قيمة مستقلة لـ `JWT_SECRET`
بطول 32 بايت عشوائي على الأقل، مثلاً:

```sh
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
```

لا ترفع `backend/.env` إلى GitHub. يستورد كل من API ولوحة الإدارة إعداد اتصال
قاعدة البيانات من هذا الملف، أو من متغيرات البيئة التي يوفّرها الخادم.

بعد الاستيراد ستكون القاعدة فارغة؛ أنشئ المستخدمين والمطاعم والمنتجات من واجهات
التطبيق. لإنشاء أول مدير، سجّل مستخدماً بالطريقة المعتادة ثم غيّر دوره من قاعدة
البيانات بعد التحقق من بريده:

```sql
UPDATE users SET role = 'admin' WHERE email = 'your-admin-email@example.com';
```

لا تستورد بيانات `final.sql` القديمة إلى بيئة عامة؛ كانت نسخة تشغيلية تحتوي
بيانات أشخاص وطلبات فعلية، وقد أُزيلت من شجرة الملفات بعد حفظ هذا المخطط.
